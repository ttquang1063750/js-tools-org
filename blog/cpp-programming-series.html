Modern C++ Programming Series: Roadmap & Curriculum

A complete guide from environment setup to OOP, memory management, and templates. Lộ trình toàn diện từ thiết lập, hướng đối tượng OOP, quản lý bộ nhớ thông minh, đến mô phỏng trực quan.

Welcome to our C++ self-study series. This course is designed to transition you from C to modern C++ concepts, including templates, OOP, smart pointers, and high-performance applications like Google's V8 engine.

Chào mừng bạn đến với chuỗi bài học tự học lập trình C++ Hiện đại (Modern C++). C++ là một ngôn ngữ lập trình hiệu năng cực cao, kế thừa từ C nhưng được trang bị thêm các mô hình lập trình mạnh mẽ như lập trình hướng đối tượng (OOP) và lập trình tổng quát (Templates). C++ là ngôn ngữ đứng sau những hệ thống phần mềm lớn nhất thế giới, bao gồm các hệ điều hành, các game engine đồ họa nặng, và đặc biệt là Google V8 JavaScript Engine - bộ não giúp trình duyệt Chrome biên dịch và thực thi JavaScript với tốc độ ánh sáng.

Dưới đây là lộ trình 8 bài học được thiết kế chi tiết nhằm giúp bạn từng bước làm chủ C++ một cách thực tế và trực quan nhất:

01

Bài 1: Thiết lập môi trường biên dịch Modern C++ và chương trình đầu tiên

Tìm hiểu về compiler C++ mới nhất, thiết lập VS Code trên macOS/Linux, cấu hình trình biên dịch dòng lệnh và viết chương trình C++ đầu tiên. Đồng thời tìm hiểu lý do Google phát triển V8 Engine bằng C++.
02

Bài 2: Modern C++ Cơ bản: std::string & std::vector

Làm quen với các cấu trúc chuẩn STL cốt lõi thay thế cho mảng và chuỗi kiểu C cũ. Tận dụng từ khóa auto, quản lý mảng động co giãn tự động và tối ưu hóa xử lý văn bản.
03

Bài 3: Lập trình hướng đối tượng (OOP) — Class, Object & RAII

Khởi đầu với triết lý hướng đối tượng trong C++. Thiết kế Class, Object, Constructor/Destructor. Tìm hiểu nguyên lý quản lý tài nguyên RAII giúp tự động giải phóng bộ nhớ.
04

Bài 4: OOP Nâng cao — Kế thừa, Đa hình & Virtual Table

Làm chủ tính kế thừa và đa hình động thông qua hàm ảo (virtual functions). Phân tích cách hoạt động của bảng hàm ảo (VTable) trong bộ nhớ lúc runtime.
05

Bài 5: Quản lý bộ nhớ thông minh với Smart Pointers

Học cách viết mã an toàn, nói không với memory leak bằng std::unique_ptr và std::shared_ptr. Tìm hiểu cách V8 engine tối ưu hóa bộ nhớ heap.
06

Bài 6: Lập trình tổng quát với Templates & STL Containers

Sử dụng Function/Class Templates để viết mã nguồn dùng chung cho mọi kiểu dữ liệu. Khai thác std::map, std::unordered_map để tăng tốc truy xuất dữ liệu.
07

Bài 7: Modern C++ Features: Lambda, Range & Structured Binding

Tìm hiểu các cú pháp hiện đại từ chuẩn C++17 trở đi giúp code cực kỳ tinh gọn: Biểu thức Lambda, structured binding, và std::optional.
08

Bài 8: Cây tìm kiếm nhị phân (BST) & Bộ mô phỏng trực quan tương tác

Ứng dụng tất cả kiến thức C++ để lập trình cấu trúc dữ liệu cây nhị phân BST, kết hợp với bộ mô phỏng trực quan Canvas chạy tương tác real-time trong trình duyệt.
