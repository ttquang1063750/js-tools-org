1. Toán Học Trong Lập Trình Sáng Tạo: White Noise vs. Coherent Noise

Trong nghệ thuật sinh ngẫu nhiên, ta thường điều khiển chuyển động của hàng ngàn hạt bụi dựa trên các Vector định hướng lực đẩy (Flowfield).

  • White Noise (Nhiễu trắng - Math.random): Trả về các giá trị ngẫu nhiên hoàn toàn độc lập và không liên quan gì đến các điểm xung quanh. Khi dùng Math.random để vẽ dòng chảy, kết quả sẽ là một chuyển động hỗn loạn, giật cục và rời rạc.
  • Coherent Noise (Nhiễu liên tục - Perlin/Simplex Noise): Trả về các giá trị thay đổi mượt mà và liên tục dựa trên tọa độ. Nếu đầu vào \(x, y\) thay đổi một lượng cực nhỏ, giá trị trả về cũng chỉ lệch một lượng nhỏ tương ứng. Điều này tạo ra các mô hình dòng chảy mềm mại mô phỏng gió thổi, sóng nước hoặc vân gỗ tự nhiên.

Nếu chưa tích hợp các thư viện Perlin Noise nặng nề, ta có thể tự viết một **Trường dòng chảy lượng lượng giác** kết hợp hàm toán học tuần hoàn:

function getTrigFlow(x, y, time) {
  // Kết hợp sin/cos của tọa độ để tạo ra chuyển động xoắn ốc liên tục mượt mà
  const angle = Math.sin(x * 0.005 + time) * Math.cos(y * 0.005 - time) * Math.PI * 2;
  return { x: Math.cos(angle), y: Math.sin(angle) };
}

2. Offscreen Canvas: Cơ Chế Bit Blitting Của Trình Duyệt

Khi bạn vẽ 1000 đối tượng phức tạp chứa bóng đổ shadowBlur và gradient lên canvas hiển thị, CPU sẽ bị tắc nghẽn nặng nề do phải tính toán rasterization (chuyển đổi vectơ sang mảng pixel) lại từ đầu cho từng đối tượng trong mỗi frame.

Giải pháp tối ưu phần cứng: Ta render hình vẽ phức tạp đó 1 lần duy nhất lên một **Offscreen Canvas (canvas đệm ẩn)**. Trong loop vẽ chính, ta sử dụng lệnh ctx.drawImage(offscreenCanvas, x, y).

[Dưới góc độ công nghệ]: Phương pháp này gọi là Bit Blitting (Bit Boundary Block Transfer). Trình duyệt chỉ cần thực hiện sao chép vùng nhớ đệm pixel có sẵn từ RAM đệm sang GPU Texture trực tiếp mà không cần giải mã vector lại, tốc độ nhanh hơn từ 10 đến 50 lần.

offscreen_blit.js 
// 1. Khởi tạo canvas ảo
const cacheCanvas = document.createElement('canvas');
cacheCanvas.width = 30;
cacheCanvas.height = 30;
const cctx = cacheCanvas.getContext('2d');

// 2. Vẽ hình phức tạp lên canvas ảo một lần duy nhất
const grad = cctx.createRadialGradient(15, 15, 2, 15, 15, 13);
grad.addColorStop(0, '#fff');
grad.addColorStop(1, '#3b82f6');
cctx.fillStyle = grad;
cctx.shadowBlur = 8;
cctx.shadowColor = '#3b82f6';
cctx.beginPath(); cctx.arc(15, 15, 12, 0, Math.PI * 2); cctx.fill();

// 3. Sử dụng drawImage để copy bộ đệm cực nhanh
function renderLoop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  particles.forEach(p => {
    // Blitting hình tròn đệm lên canvas thật
    ctx.drawImage(cacheCanvas, p.x - 15, p.y - 15);
  });
  requestAnimationFrame(renderLoop);
}

3. Web Workers: Đa Luồng Song Song (Multithreading)

Mặc định, JavaScript chạy đơn luồng (Single-threaded) trên Main Thread (luồng giao diện người dùng). Nếu bạn có 10,000 hạt bụi cần tính toán va chạm và cập nhật tọa độ vật lý, luồng chính sẽ bị nghẽn, giao diện người dùng bị đơ cứng (UI Freeze).

Giải pháp: Đưa toàn bộ tính toán toán học xuống chạy dưới **Web Worker** chạy ở luồng nền độc lập của hệ điều hành.

sequenceDiagram participant MT as Main Thread (Luồng chính UI) participant WW as Web Worker (Luồng nền CPU) MT->>WW: Gửi lệnh start + mảng toạ độ trống loop Tính toán vật lý WW->>WW: Tính toán va chạm / Vector chuyển động end WW->>MT: Gửi lại mảng toạ độ mới (Transferables) MT->>MT: Dùng drawImage vẽ cực nhanh lên Canvas

Khi giao tiếp giữa Main Thread và Web Worker, ta cần truyền dữ liệu mảng nhị phân có định dạng **Transferable Objects (như ArrayBuffer)** thay vì object thông thường (Structured Clone). Transferable truyền vùng nhớ vật lý trực tiếp mà không cần copy bộ nhớ, giúp tốc độ truyền dữ liệu gần như tức thời (0ms overhead).

4. WebGL Context: Sức Mạnh Song Song Của GPU

Khi số lượng hạt lên tới 100,000 hạt, CPU của máy tính sẽ chạm giới hạn tốc độ xử lý đơn luồng. Lúc này, ta cần chuyển sang sử dụng **WebGL context**.

Tính chất Canvas 2D API WebGL API
Xử lý bởi CPU (Đơn luồng phần lớn) GPU (Xử lý song song đa luồng)
Kiểu vẽ Immediate Mode (Vẽ vẽ ngay lập tức) Retained / Shader Pipeline (GLSL code)
Giới hạn hạt Dưới ~5,000 hạt ở 60 FPS Hơn ~200,000 hạt ở 60 FPS

WebGL nạp toàn bộ toạ độ hạt vào **VBO (Vertex Buffer Object)** trên bộ nhớ của Card đồ họa một lần duy nhất, sau đó GPU sử dụng hàng ngàn nhân xử lý đồ họa nhỏ để chạy mã Shader (GLSL) đồng thời, mang lại hiệu năng mô phỏng cực hạn.
